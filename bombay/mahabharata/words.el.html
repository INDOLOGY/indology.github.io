The words.el program

Words.el is an Emacs Lisp program for use with the Unix editor Emacs. (It makes use of a command "mbh-query-replace-regexp", which is defined in the program mqreplace.el.) Its purpose is to present the user with every occurrence in the MBh of certain common words and ask whether the following space should be removed. As each command is completed I comment it out with a ";" -- it can be seen that there is a long way still to go! An equivalent task for names is performed by names.el.

Note that the original program makes direct use of accented characters in the CSX encoding; here it has been converted to use Unicode equivalents to ensure readability on modern computers. This means that downloading and attempting to run the program as it stands is unlikely to work.
